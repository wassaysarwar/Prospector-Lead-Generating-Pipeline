# Sample output

A real 10-lead run (roofing / Leeds), included to show the exact output schema
and the quality of the three problem tiers the pipeline produces.

- [`sample_output_roofing_leeds.xlsx`](sample_output_roofing_leeds.xlsx) — native format
- [`sample_output_roofing_leeds.csv`](sample_output_roofing_leeds.csv) — same data, CSV

> **Privacy:** the personal **contact fields** (`email`, `website_contact_email`,
> `phone`, `whatsapp_phone`) are **masked** (e.g. `lxxxx@domain.co.uk`,
> `+44113xxxxxx`). A live run produces full, verified values. No real personal
> data is published in this repository.

Each row is a contactable, qualified prospect with three ready-to-use, fact-based
talking points (technical / competitive / opportunity) for cold outreach.
